# ESP32-Controlled DC-DC Buck Converter PCB

PCB design project for an ESP32-controlled DC-DC Buck Converter, developed using EasyEDA.

## Overview

This repository contains the schematic and PCB layout files for a DC-DC Buck Converter control system based on an ESP32.

The project was designed in EasyEDA and includes the editable source files required to open and continue working on the design.

## Project Files

- `1-Schematic_Pro_CTRL_2_Buck.json`  
  EasyEDA schematic file.

- `1-PCB_PCB_Pro_CTRL_2_Buck.json`  
  EasyEDA PCB layout file.

## How to Open the Project in EasyEDA

1. Open EasyEDA.
2. Go to **File → Open → EasyEDA**.
3. Select the desired `.json` file.
4. Open the file in the editor.
5. Save it into an EasyEDA project if you want to continue editing it.
